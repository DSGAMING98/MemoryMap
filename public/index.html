PROJECT REPORT

Methodology and measured results

A concise, defensible account of the dataset, model, evaluation, and limitations.

Open GitHub
01

Research problem

Can learning-history data predict memory retention and recommend better revision intervals than a fixed forgetting curve?

02

Dataset

12,854,226 anonymized Duolingo traces from Settles and Meeder (ACL 2016), processed in 250,000-row chunks.

03

Training design

A deterministic one-million-row uniform sample; 810k training, 90k validation, and 100k untouched chronological test rows.

04

Selected model

Random Forest with 40 trees, depth 12, minimum leaf size 8. Inputs: delay, prior exposures, and prior accuracy.

HONEST CONCLUSION

What the evidence supports

The implementation proves that prospective prediction, threshold scheduling, and delayed-recall validation can be integrated without using current outcomes as inputs. The low R² means the three public-history features explain little event-level variation, so MemoryMap does not claim that full personalization has already been proven. It provides the infrastructure to test that claim once enough genuine longitudinal outcomes exist.
